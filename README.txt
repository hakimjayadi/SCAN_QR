SPPG CIBADAK110 — Brightly Style
==================================
Website dibuat ulang mengikuti karakter visual gambar referensi:
- container rounded seperti mobile landing page
- navbar putih dengan pill button
- hero dua kolom dengan ilustrasi menu
- stats card
- grid 3x2 untuk informasi menu
- section informasi gizi
- QR Code
- footer CTA
- responsive handphone/tablet/PC
- motion floating, reveal on scroll, dan mouse parallax

Edit konten di index.html.
Edit warna/layout di style.css.
Edit QR, mobile menu, reveal dan parallax di script.js.

Ganti assets/menu-illustration.svg dengan foto menu asli jika sudah tersedia.
